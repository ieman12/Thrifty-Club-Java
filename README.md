# Thrifty Club Store Simulation (Java)

This Java project models a private members-only grocery store system.  
Members can register, select an item, and go to the checkout to pay.  
It demonstrates interaction between multiple classes (`Member`, `Item`, `Store`) and simulates real-world OOP relationships.

This was part of my Programming 1 coursework and helped me practise **parameter passing**, **accessor/mutator methods**, and **external method calls**.

## Features
- Member registration with ID and PIN  
- Store entry with welcome message  
- Item selection and price display  
- Checkout system that calculates change  
- Demonstrates object interaction across classes  

## Technologies
- Java  
- BlueJ IDE
